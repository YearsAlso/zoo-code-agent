## Purpose

定义会话状态的持久化与重启续跑，使一次 agent 会话不因进程退出而丢失。该能力复用框架既有的状态落盘与原子写能力，本仓库不自建落盘格式。

## ADDED Requirements

### Requirement: 会话状态 MUST 经框架状态机持久化

会话的累积记录 SHALL 写入框架的状态作用域，MUST NOT 由本仓库自建落盘格式。

#### Scenario: 会话开始时创建状态作用域
- **WHEN** 启动一次新会话
- **THEN** 框架状态机中出现以该会话标识命名的作用域

#### Scenario: 记录写入后可立即读回
- **WHEN** 一次会话写入若干条记录
- **THEN** 在同一进程内读回这些记录，内容与顺序与写入一致

### Requirement: 进程重启后 MUST 可续跑

进程退出后重新启动，同一会话 SHALL 能读回此前的记录，并从上次中断处继续，而非从头开始。

#### Scenario: 重启后读回既有记录
- **WHEN** 写入若干轮记录后退出进程，再以同一会话标识启动
- **THEN** 此前的记录全部可读回，且顺序不变

#### Scenario: 续跑不重复已完成的工具副作用
- **WHEN** 在工具调用已产生副作用之后重启并续跑
- **THEN** 该工具不再次产生副作用

#### Scenario: 未落盘的记录不被假装为已保存
- **WHEN** 在一次会话中写入记录但尚未经过框架的落盘时机，此时进程退出
- **THEN** 重启后如实反映最后一次成功落盘的状态，MUST NOT 声称包含了未落盘的记录
