## ADDED Requirements

### Requirement: 终端渲染器 MUST 原地显示增量，管道与 JSON MUST NOT 因此变形

终端渲染器 SHALL 把正文增量**原地**写出（不插入换行）并即时刷新，使长回答边生成边可见。
已经以增量呈现过的正文，在定稿时 MUST NOT 再整段重复打印。

管道渲染器（``plain``）SHALL 忽略增量，行为与引入流式之前**逐字节一致**；事件流渲染器
（``json``）SHALL 把增量作为独立事件行输出，且输出 MUST 仍然每行一个 JSON 对象。

#### Scenario: 终端里原地可见
- **WHEN** 一轮产生多段正文增量
- **THEN** 终端渲染器的输出里，这些增量按顺序拼接且不插入额外换行

#### Scenario: 定稿不重复
- **WHEN** 正文已经以增量呈现过，随后收到定稿事件
- **THEN** 正文 MUST NOT 出现第二遍

#### Scenario: 管道行为不变
- **WHEN** 输出不是终端（管道 / CI）
- **THEN** 输出与引入流式之前逐字节一致，且不含任何增量痕迹

#### Scenario: 事件流仍然合法
- **WHEN** 以事件流模式运行并产生增量
- **THEN** 每一行仍是可解析的 JSON 对象
