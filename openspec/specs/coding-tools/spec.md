# coding-tools Specification

## Purpose
定义 coding agent 的工具面：只读检索、文件写入、精确编辑与命令执行，以及它们共同遵守的工作目录边界。本能力**取代** `add-minimal-agent-loop` 中「工具集不含写/执行能力」的承诺——只读是起点，不是终点。

## Requirements

### Requirement: 工具集 MUST 提供写、编辑与执行能力

工具集 SHALL 提供至少一个写入工具、一个精确编辑工具与一个命令执行工具，使 agent 能在工作目录内完成"读 → 改 → 跑"的闭环。

#### Scenario: 写入文件
- **WHEN** 调用写入工具并给出路径与内容
- **THEN** 文件被创建或覆盖，父目录不存在时被创建，返回结果区分「创建」与「覆盖」

#### Scenario: 精确编辑唯一匹配
- **WHEN** 待替换文本在文件中恰好出现一次
- **THEN** 该处被替换，返回被替换的处数

#### Scenario: 编辑未匹配时报错而非静默无操作
- **WHEN** 待替换文本在文件中不存在
- **THEN** 返回工具错误，且文件内容 MUST NOT 改变

#### Scenario: 编辑多处匹配时要求显式全量替换
- **WHEN** 待替换文本出现多次且未显式请求全量替换
- **THEN** 返回工具错误并说明匹配次数

#### Scenario: 执行命令返回退出码与输出
- **WHEN** 执行一条命令
- **THEN** 返回 `exit_code` 与 stdout/stderr；非零退出同样是正常返回，而不是异常

#### Scenario: 命令超时与输出超长都不抛异常
- **WHEN** 命令超过给定超时，或输出超过上限
- **THEN** 以「超时」或「截断并标注」的形式返回观察，MUST NOT 让会话因异常中断

#### Scenario: 命令在声明的工作目录内执行
- **WHEN** 执行一条命令
- **THEN** 其工作目录为声明的工作目录

### Requirement: 工具 MUST NOT 越过声明的工作目录

所有工具——不只读工具——SHALL 先把候选路径解析为规范形式，再校验其落在声明的工作目录之内；越界 MUST 以错误返回，且 MUST NOT 产生任何副作用。

#### Scenario: 相对路径越界被拒绝
- **WHEN** 以 `..` 越出工作目录
- **THEN** 返回越界错误，工作目录外的文件 MUST NOT 被读写

#### Scenario: 符号链接越界被拒绝
- **WHEN** 工作目录内的符号链接指向目录之外
- **THEN** 解析后被判定为越界并拒绝

### Requirement: 工具集 MUST NOT 提供代码求值能力

工具集 MUST NOT 暴露 `eval` 或 `exec` 一类"在框架进程内直接求值"的能力：那会绕过权限门，把授权边界变成装饰。

#### Scenario: 不存在代码求值工具
- **WHEN** 枚举工具集
- **THEN** 其中不含任何代码求值类工具

### Requirement: 检索类工具 MUST 有界

内容检索与文件名检索 SHALL 设置结果上限并在达到上限时显式标注，MUST NOT 返回无界结果。

#### Scenario: 结果达到上限
- **WHEN** 匹配数量超过上限
- **THEN** 仅返回上限条并标注已达上限

#### Scenario: 跳过缓存与版本库目录
- **WHEN** 工作目录内含 `.git`、虚拟环境或缓存目录
- **THEN** 这些目录不出现在检索结果里
