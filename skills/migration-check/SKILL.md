# 迁移检查

改动任何表结构 / 模型字段时，按这个顺序做：

1. 先找迁移目录（常见：`scripts/migrations/`、`migrations/`、`alembic/versions/`），列出已有脚本，
   确认最新的那条是你将要接上的基线。
2. 新迁移 MUST 幂等：建表 / 加列用 `IF NOT EXISTS`，复杂改动用 `DO $$ ... $$` 块包裹，
   保证重复执行不出错。
3. 每条新迁移配一份回滚脚本，命名与正向脚本对齐。
4. 整段 DDL 用事务包裹；**不要把 DDL 拆成多条独立事务**，否则失败时会留下半张表。
5. 改完在本地跑一次迁移命令，确认退出码为 0，再统一跑一次应用的测试。

不要直接改生产表结构，也不要删掉已有的迁移文件——它们是历史，不是草稿。
